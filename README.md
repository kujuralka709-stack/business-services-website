# Veda Technology – Professional Business Website

## 📌 Project Overview

The Veda Technology Website is a professional and responsive business website developed to represent a technology and digital-services organization.

The website provides information about technology programs, IT services, training opportunities, internships, company information, FAQs, and contact details.

This project is developed as part of an internship task to practice front-end web development skills.

## 🎯 Project Objectives

- Create a professional business website.
- Design a responsive layout for different screen sizes.
- Develop reusable sections and cards.
- Add interactive JavaScript functionality.
- Implement basic SEO practices.
- Improve practical HTML, CSS, and JavaScript skills.

## 🛠️ Technologies Used

- **HTML5** – Website structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Interactive functionality.
- **Git** – Version control.
- **GitHub** – Project hosting and repository management.

## ✨ Features

1. **Homepage** – Professional landing page with navigation.
2. **About Us** – Company introduction, vision, and mission.
3. **Technology Programs** – Displays different technology learning areas.
4. **IT & Digital Services** – Showcases digital service categories.
5. **Internship & Training** – Information about learning and internship opportunities.
6. **FAQ Section** – Interactive accordion for frequently asked questions.
7. **Contact Section** – Contact form with front-end validation.
8. **Responsive Navigation** – Mobile-friendly navigation menu.
9. **SEO Optimization** – Meta description, keywords, and page title.
10. **Footer** – Quick navigation and copyright information.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. The website will open in your browser.
